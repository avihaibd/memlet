# מם או… — Memo! נזכרתי. (Memlet)

אפליקציית ווב בעברית לאימון זיכרון ולסדר ביומיום — בקובץ HTML אחד, בלי התקנה.

## מה יש בפנים
- **היום** — תפיסה מהירה (משימה / 📞 להחזיר שיחה / 🙋 ביקשו ממני / 💭 מחשבה מהדרך), רשימה / קנבן / גאנט, חנייה של משימות שעזבתם באמצע, חימום קשב לפני משימה, "מה שכחתי?" עם שאלות מותאמות, אתגר זיכרון יומי.
- **ממו וכלים** — פתקיות צבעוניות; 🚗 איפה חניתי (עם תמונה); 🎤 שינון טקסט (צילום/הדבקה, האזנה, תמונה לשורה, אותיות ראשונות, העלמה, השלמת מילים, סדר שורות, מבחן כתיבה); 🏋️ רצפי תרגילים (יוגה, שחייה…); 📖 חומר למבחן עם חזרות עד התאריך.
- **חזרות** — חזרה מרווחת (spaced repetition) לנושאים לטווח ארוך.
- **אימון** — תרגילי חשיבה (חשבון, סדרות, יוצא דופן, שטף מילים), מעקב מיומנות חדשה, טבלת שולטה, שמות ופרצופים, רצף מספרים (רגיל והפוך), רשימת מילים, מה חסר?, מצא את הזוג, סודוקו (עם טיוטות, ביטול ומילוי אפשרויות).
- **שיטות וטיפים** — 20 כרטיסי שיטות זיכרון ו־54 טיפים עם הרחבה (תזונה, בריאות, שינה, תנועה, הרגלים, טכנולוגיה, ריכוז).
- **התקדמות** — רצף ימים, שיאים, גרף פעילות, גיבוי ושחזור.

## הרצה
- אונליין: https://avihaibd.github.io/memlet/ (GitHub Pages) — אפשר להתקין למסך הבית ולעבוד גם בלי אינטרנט.
- מקומית: לפתוח את `index.html` בדפדפן.

הנתונים נשמרים בדפדפן של כל מכשיר (localStorage). לסנכרון בין מכשירים — ייצוא/שחזור גיבוי, או בעתיד Supabase.
