# מם או… — Memo! נזכרתי. (Memlet)

אפליקציית ווב בעברית לאימון זיכרון ולסדר ביומיום — בקובץ HTML אחד, בלי התקנה.

## מה יש בפנים
- **היום** — תפיסה מהירה (משימה / 📞 להחזיר שיחה / 🙋 ביקשו ממני / 💭 מחשבה מהדרך), רשימה / קנבן / גאנט, חנייה של משימות שעזבתם באמצע, חימום קשב לפני משימה, "מה שכחתי?" עם שאלות מותאמות, אתגר זיכרון יומי.
- **ממו** — פתקיות צבעוניות עם חיפוש ונעיצה.
- **חזרות** — חזרה מרווחת (spaced repetition) לנושאים לטווח ארוך.
- **אימון** — טבלת שולטה, שמות ופרצופים, רצף מספרים (רגיל והפוך), רשימת מילים, מה חסר?, מצא את הזוג, סודוקו.
- **שיטות וטיפים** — 15 כרטיסי שיטות זיכרון ו־33 טיפים (תזונה, שינה, תנועה, הרגלים).
- **התקדמות** — רצף ימים, שיאים, גרף פעילות, גיבוי ושחזור.

## הרצה
פשוט לפתוח את `index.html` בדפדפן. הנתונים נשמרים ב־localStorage של הדפדפן.
